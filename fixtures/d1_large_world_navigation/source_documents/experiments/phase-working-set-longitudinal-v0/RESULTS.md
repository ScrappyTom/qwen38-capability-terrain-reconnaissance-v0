# Phase working-set longitudinal v0 results

Status: **complete; core fresh-world continuity observed, no automatic phase policy promoted**

Date: 2026-08-17

## Verdict

Across one three-phase coding workflow and one three-phase research workflow, the complete
conversation was not necessary for core continuity. Beginning each continuation phase from the
complete current task/purpose, exact current candidate, and ordinary tools was enough to recover
all task-grounded code behavior and every required research distinction through two authority
changes.

The transcript remained useful navigation state. It avoided rereading unchanged sources and
usually completed in fewer calls. It also accumulated enough prompt history to leave only 854
completion tokens at the final code action, causing an otherwise valid whole-file action to end
in incomplete JSON at the exact 25,088 combined ceiling.

This supports bounded phase reentry as a removable operating technique. It does not support
automatic resets, a phase router, a semantic checkpoint, a plan/card system, or the claim that
history is useless.

## Qualification and execution

The experiment-local `replace_file(path, expected_file_sha256, new_content)` provider qualified
before the study. Its saved-boundary action was 57.6% the serialized size of the prior old-plus-
new exact patch; the live Qwen qualification selected it, made the exact successor, passed the
check, submitted, and replayed in six calls. The stable `workbench/` was unchanged.

R1 is preserved but ineligible because its checker imposed two task-unstated conventions. R2
repeated the same T-versus-W methods after only task-entailed checker corrections. All ten R2
runs, literal requests, responses, actions, results, candidates, historical runtime sources,
runtime profile, full 66/66 offload, and clean server stop are verified.

## Code result

At the first complete audit in all four Phase-B/Phase-C cells, every external product predicate
passed. The model correctly carried replacement, lifetime order, removal, deferral, boundaries,
priority/FIFO ordering, and validation through both authority changes.

Three cells nevertheless had one wrong model-authored assertion:

- fresh-world B expected priorities 10, 5, 3 as `x,z,y` rather than `x,y,z`;
- transcript C expected a priority-2 item before a priority-3 item when deferral expired; and
- fresh-world C inherited the same `x,z,y` assertion.

Direct execution found exactly 1/13, 1/17, and 1/20 failing model-authored tests respectively.
The corresponding product implementations all passed the task-grounded external audit.

R2's visible result exposed only `model_authored_tests_pass:false`, not pytest stdout/stderr.
Therefore the post-failure repair sequences are feedback-surface limited. They do not show that
Qwen received and ignored the exact assertion mismatch. The current forward apparatus now
returns literal diagnostics and proves their visibility with a failing preflight sentinel; R2
was not rerun or rewritten.

A later authentic maintenance audit also found that this post-run verifier did not prove the
saved manifest/source set was complete. The forward repair now requires exact agreement among the
historical runtime-source set, saved manifest, and saved source directory; validates canonical
manifest identity; and includes `verify_r2.py` in the current source lock. All ten historical R2
runs still verify at 17 runtime-source files each. This correction does not change the R2 model
result. See [`POSTRUN_CUSTODY_COMPLETENESS_CORRECTION.md`](POSTRUN_CUSTODY_COMPLETENESS_CORRECTION.md).

Both methods submitted complete current memos in both continuation phases and passed the
corrected supporting audit.

The one fresh-world-B extrapolation said safety outcomes were not measured under the future

Across research Phases B/C, transcript used 15 calls and 164,389 total tokens; fresh world used

History helped navigation; reacquisition preserved semantic coverage at lower accumulated
context but not lower wall-clock cost.

## Earned operating model

- Keep exact world, versions, sources, checks, and full history outside the prompt.
- Use the ordinary transcript within a coherent phase.
- At a meaningful authority or work-phase boundary, a fresh actor can reconstruct from the
  complete task/purpose and exact current world when accumulated history is no longer useful or
  threatens action headroom.
- Keep task/source authority separate from model-authored code, tests, memos, plans, and
  summaries. Currentness does not make a derivative authoritative.
- Treat prompt capacity, response/action capacity, semantic binding, product behavior,
  self-authored verification, and closure as separate outcomes.
- Before diagnosing repair, verify that the model-facing check contains the exact diagnostic,
  not merely an aggregate red/green field.

## Decision

Retain the stable custody laboratory and the qualified replacement provider as removable
experimental infrastructure. Retain transcript and fresh-world reentry as comparison methods.
Promote neither as a universal default and do not add a semantic checkpoint.

This three-phase study already answers the immediate continuity question at bounded local scale.
Do not rerun it merely to exploit the improved diagnostic. The next authentic code workflow may
use the corrected check surface, but another phase-policy experiment should wait for either a
larger real working set, a continuity loss under fresh reentry, or a recurring cost/capacity
boundary that the current method cannot handle.
