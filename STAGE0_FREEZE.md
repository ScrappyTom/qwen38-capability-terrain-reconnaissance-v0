# Capability-terrain reconnaissance v0 — Stage 0 freeze

Date: 2026-08-23

Status: offline apparatus and fixture qualification passed; no model calls
authorized

## Decision

Freeze one finite breadth-oriented observation tranche across five exact task
lineages and six trajectories. The tranche asks where useful work stops under
ordinary exact chronology and ordinary artifact operations. It does not compare
memory formats, estimate natural-task prevalence, or promote a context
architecture.

The maximum measured envelope is 42 actor calls and 1,053,696 serialized actor
tokens. Every malformed, null, incomplete, harmful, or successful trajectory
consumes its declared slot. There is no automatic extension, replacement,
second seed, or successor experiment.

## Ordinary chronology and capacity safety

The measured actor uses ordinary append-only task/action/result chronology.
Every accepted result counts as delivered only when it appears in a later
model request. The runtime preserves exact requests, raw responses, parsed
actions, results, mutation effects, candidate snapshots, check output, and
delivery state.

If a prospective request exceeds 20,992 prompt tokens, the host may apply the
already-qualified conservative safety operation: scan previously delivered
exact results in frozen oldest-first order, replace one body at a time with an
exact reopen receipt, recount, and stop immediately at the first feasible
packet. The pending result is protected. This is safety substrate, not the
research treatment.

The selected short cells are not expected to require relief. If it activates,
the event is reported literally rather than hidden.

## Evaluators and currentness

Checks are bound to the exact candidate they evaluate. A later mutation makes
the earlier check stale. Raw evaluator output is kept exactly; model-visible
check output is a deterministic projection containing stable test/case names,
pass/fail status, the evaluated candidate, and explicit currentness. TAP
durations and absolute paths are not treated as semantic evidence.

D3–D5 retain their exact external artifact graders and protected-file checks.
D4 additionally uses the frozen `d4_plain_object_grade.mjs` supplement because
the inherited eight-case grader did not distinguish arrays from dates, maps,

grader remains intact and both components must pass.
D2 retains the original six-case visible and sixteen-case hidden machine
grades, but readiness is not delegated to the lexically narrow hidden grade.
`qualification/D2_REQUIREMENT_RUBRIC.json` freezes thirteen task-level criteria
covering protected scope, all three edited sections, citation binding,
cross-section consistency, and unsupported claims. All criteria must be met
and no blocking unsupported claim may remain for closure readiness.
`ADJUDICATION_PROTOCOL.json` freezes the candidate/task/evidence bindings and
required criterion-level record. Runtime records D2 readiness as
`not_adjudicated`; no readiness or utility claim is made until that separate
post-run record exists. The adjudication is not actor-visible and cannot alter
the measured trajectory.

The host-only D2 qualification gold has a separate frozen adjudication under
`qualification/adjudications/`: all thirteen criteria are `met`, both fresh
candidate-bound machine checks pass, no blocking unsupported claim remains,
and the frozen rule yields `ready`. This proves evaluator attainability only;
it does not pre-adjudicate any measured candidate.

Artifact correctness, check behavior, final-response compliance, submission,
and readiness remain separate outcomes.

## D6 admissibility

After D2–D5, the host selects the first changed terminal candidate in fixed
order. Candidate quality does not influence selection.

The fresh packet may include only:

- exact original task text;
- exact current mutable-candidate bytes and version;
- mutable path and declared visible-check identity;
- the latest check body only if it is current for that candidate;
- otherwise an explicit no-current-check state and identity-only stale handle;
- identity/hash/size/reopen receipts for prior observations; and
- the same task-native accessible world and actions.

It excludes construction chronology, prior final response, old observation
bodies, hidden grades, readiness, gold, and investigator-selected unread
evidence. If no candidate changed, D6 consumes its slot with zero calls and no
backup.

## Valid claims and nonclaims

This tranche can map literal behavior at discovery, relationship formation,
binding, action organization, admission, effect uptake, feedback, repair, and
closure boundaries. It can show whether a capability became observable within
the frozen horizon.

It can observe whether exact evidence is used in a later action or artifact.
The bare-action interface does not separately expose latent relationship
formation before action binding, so the tranche cannot grade unexpressed
internal relationships.

It cannot establish:

- prevalence across natural tasks;
- causal differences among domain, task, or action interfaces;
- a generally best memory or context architecture;
- independent replication from D6;
- inability when a call or expression ceiling prevents observation; or
- positive task value from fewer calls, changed behavior, or submission alone.

No measured inference may begin until the frozen commit is pushed and the owner
separately authorizes that exact commit, run ID, 42-call ceiling, one attempt per
call, and zero retries.
