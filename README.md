# Qwen3.8 capability-terrain reconnaissance v0

This repository materializes the first breadth-oriented discovery tranche from
the bounded-context experimental program. It is an exploratory observation
bank, not a memory-mechanism comparison and not an estimate of task prevalence.

The frozen portfolio contains six trajectories across five exact
source/candidate lineages:

- D1: four-decision navigation in a 766,502-byte external evidence atlas;
- D2: evidence-bound paper revision;
- D3: ordinary-success coverage-window calibration;
- D4: rule-dense device-event construction;
- D5: deployment-wave action/effect/repair;
- D6: conditional exact-current-state review of the first changed D2-D5
  candidate.

Stage 0 is offline. It vendors exact source bytes from pinned Git objects,
freezes the action and evaluation geometry, validates starting and known-good
worlds, and qualifies all D6 branches. No model inference is authorized by the
Stage 0 commit.

See `STAGE0_FREEZE.md` and `STAGE0_QUALIFICATION.json` after materialization.
